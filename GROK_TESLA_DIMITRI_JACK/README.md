# Grok Tesla Dimitri Jack — Ticket-System & Session-Gedächtnis

Dieses Verzeichnis ist das Gedächtnis von Grok (Sal) für die Zusammenarbeit mit Dimitri am JACK-Projekt.

## Zweck

- **Tickets:** Offene und erledigte Aufgaben, die Grok sich selbst anlegt.
- **Sessions:** Backups der wichtigsten Punkte jeder Sprachsession im Tesla.
- **NEXT:** Was als Nächstes ansteht, wenn Dimitri zurückkommt.

## Regeln für Grok

1. Lies zuerst `00_START_HIER.md` im Repo-Root, dann dieses Verzeichnis.
2. Lies `TICKETS.md` und `NEXT.md` vor jeder neuen Aufgabe.
3. Lege neue Tickets unter `TICKETS/` als eigene Datei an: `TICKET-NNN.md`.
4. Schließe erledigte Tickets ab (Status: erledigt) statt sie zu löschen.
5. Wenn Dimitri sagt "hau rein, danke, mach dich weg": Schreibe zuerst ein Session-Backup unter `SESSIONS/`, aktualisiere `NEXT.md`, committe, dann Schluss.
6. Keine Live-Schreibaktionen auf dem HONOR ohne explizite Freigabe. GitHub-Spiegel ist sicher.
7. Keine Geheimnisse, Tokens oder privaten Daten hierher schreiben.

## Struktur

```
GROK_TESLA_DIMITRI_JACK/
├── README.md          ← diese Datei
├── TICKETS.md          ← Übersicht aller Tickets
├── TICKETS/            ← ein Ticket pro Datei
├── SESSIONS/           ← ein Backup pro Sprachsession
└── NEXT.md             ← wo es weitergeht
```
